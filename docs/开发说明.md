# 深清 开发说明

## 1. 分层

```
QML 界面（src/shenqing/qml）
        │  属性和 Slot
AppBridge（bridge/app_bridge.py，QML 里的 App 对象）
        │
SessionController  ProcessGuard  StatsStore  Blocklist  Settings
（core/…）                                     （系统集成：AutostartManager / TrayController）
```

- **唯一入口**：`run.py` → `shenqing.app.main()`。
- **界面与逻辑**：QML 不写业务，只读 `App` 的属性、调 `App` 的 Slot；Python 不碰控件，只发信号。
- **数据目录**：`%APPDATA%\ShenQing\`（`settings.json` / `stats.json` / `blocklist.json` / `logs/app.log`）。

## 2. 关键文件

| 文件 | 职责 |
| --- | --- |
| `src/shenqing/app.py` | QApplication、单实例锁、RinUIWindow 引导、主题、托盘、`--smoke` 冒烟 |
| `src/shenqing/bridge/app_bridge.py` | 全部 QML 可见的 Property / Slot / Signal |
| `src/shenqing/core/session.py` | 倒计时会话状态机（idle/running/paused）、暂停次数上限 |
| `src/shenqing/core/guard.py` | ctypes 调 Win32 枚举/结束进程，QTimer 轮询 |
| `src/shenqing/core/stats.py` | 专注记录 JSON + 今日/本周/连续天数/近7天 + CSV 导出 |
| `src/shenqing/core/blocklist.py` | 进程黑名单 + 预设分组 |
| `src/shenqing/services/autostart.py` | HKCU Run 注册表项 |
| `src/shenqing/services/tray.py` | 系统托盘菜单 |
| `src/shenqing/qml/Main.qml` | FluentWindow + 四个导航页 + 全屏锁机遮罩 |

## 2.5 v0.2 增量：空间 / 应用清单 / 插件

- **空间（Space）**：`core/spaces.py` 管理 `spaces.json`；每张卡 = 名称 + 时长（15–240，吸附 5 分钟）+ 氛围 + 白名单进程；超禅唯一（super），其余进「轻禅」分组。
- **应用清单**：`core/app_catalog.py` 扫开始菜单 `.lnk` → WScript.Shell 解析目标 exe → QFileIconProvider 抓图标（缓存 `%APPDATA%\ShenQing\icons\`）→ 关键词粗分类（办公软件/教育学习/实用工具/其他）。结果缓存 `apps.json` 12 小时。
- **插件**：`plugins/` 提供 manifest 校验、`PluginBase` 生命周期钩子、`PluginManager`（扫描/加载/启用停用/事件分发/异常隔离）；bridge 在 `session_start/session_end/tick/process_blocked` 时 dispatch。详见 [插件开发.md](插件开发.md)。
- **桥接口契约**：`docs/契约_v0.2.md`（QML 只认这份）。
- **液态玻璃着色器**：`qml/glass/LiquidGlass.qml` + `qml/glass/shaders/liquid_glass.frag|vert`。
  原理同 CW2 的液态玻璃主题（`F:\Class Widgets 2 开发\Class Widgets 2 外观\液态玻璃`）：
  用 `ShaderEffectSource` 采样 App 自己的 `Backdrop`，片段着色器做圆角透镜折射、色散彩边、
  左上镜面高光、1px 玻璃壳高光，磨砂（frost）默认几乎关闭。
  **改完 shader 必须重新编译**（Qt 6 + D3D11 只吃带 HLSL 的 qsb）：
  ```powershell
  cd src\shenqing\qml\glass\shaders
  pyside6-qsb --qt6 -b -o liquid_glass.vert.qsb liquid_glass.vert
  pyside6-qsb --qt6     -o liquid_glass.frag.qsb liquid_glass.frag
  ```
  QML 属性顺序必须与 shader 里 `uniform buf` 声明顺序一致（qt_Matrix/qt_Opacity 在前）。
  `sourceItem` 必须传背景层（Backdrop），不能传卡片自身容器，否则递归采样。
- **全局玻璃控件**：`GlassButton`（胶囊/圆钮）、`GlassSwitch`、`GlassSlider`、导航轨选中态、`GlassRow` 悬停态都套一层 `LiquidGlass`。
  交互参数：`hover`（0→1，160ms）+ `sweep`（-1 关闭；悬停时 -0.2→1.2，约 820ms 扫过一道高光）。
  采样纹理自动外扩 `pad`（min(w,h)*0.35，12–32px），保证边缘折射能采到卡片外侧；`live` 默认 false（背景静态，纹理只渲一次，动画只改 uniform）。
  注意：**不要把 LiquidGlass 做得比控件大**（会破坏坐标映射）；**不要在玻璃后面放半透明矩形/矩形投影**（会透过玻璃显示成黑框）。

## 2.6 v0.3 增量：海洋 / 遮罩 / 灵动岛 / SMTC / 通知 / 速启面板

- **视觉**：海洋色板在 `qml/components/Constants.js`；`Backdrop` 深海→浅海渐变 + 三团水光；图标 `assets/icon.png` 由 `scripts/make_icon.py` 生成（水滴 + 涟漪）。
- **遮罩**：`components/LockOverlay.qml`，`App.locked` = 任何会话为 true；左侧倒计时 + 右侧 `components/MediaIsland.qml`；轻/中度显示暂停/提前结束，重度不显示且 bridge 拒绝。
- **SMTC**：`services/media_smtc.py`，后台线程跑 asyncio 轮询 `GlobalSystemMediaTransportControlsSessionManager`（1s），信号回主线程；bridge 暴露 `mediaTitle/mediaArtist/mediaAlbum/mediaApp/mediaPlaying/mediaPosition/mediaDuration/mediaHasSession` + `mediaToggle/mediaNext/mediaPrev`。
- **通知**：`services/notifications.py`，注册 `HKCU\Software\Classes\AppUserModelId\ShenQing.ShenQing`（DisplayName/IconUri），用 WinRT Toast；失败回退托盘气泡。专注结束/完成时发送。
- **速启面板**：`qml/QuickPanel.qml`（375×475，CW2 TrayPanel 形态），右键托盘打开：`app.py` 用托盘/光标坐标定位并 `requestActivate`；面板内按钮通过 `App.startLevel/startSpace/showMainWindow/gotoSettings/quitApp` 操作，失焦自动隐藏。

## 3. 启动流程

1. 解析参数 → 设置控制台 UTF-8（RinUI 会打印 emoji，GBK 控制台会崩）。
2. 建 `QApplication`，设置应用名/图标。
3. `QLockFile` 单实例锁。
4. 建 `AppBridge`，`RinUIWindow()` 先建引擎，再把 bridge 绑成 QML 上下文对象 `App`，最后 `load(Main.qml)`。
5. 非冒烟模式挂托盘；`--smoke` 模式 3 秒后逐页实例化 + 截图 + 退出（退出码 1 = 有 QML 报错）。

> 注意：必须「先建窗口对象、后 load」，因为 QML 一加载就会读 `App`，上下文属性晚了会拿到 null。

## 4. 冒烟测试

```powershell
# 离屏（不开窗）
$env:QT_QPA_PLATFORM="offscreen"; $env:QT_QUICK_BACKEND="software"
python run.py --smoke   # 退出码 0 表示四个页面都能实例化，build/smoke.png 为截图
```

单元测试（不需要 GUI）：

```powershell
python -m unittest discover -s tests -v
```

## 5. 打包

`scripts/build_exe.ps1` 读取 `packaging/ShenQing.spec`；`onedir` 出绿色目录并压 zip，`onefile` 出单文件 exe。
打包后 QML 与 assets 位于 `sys._MEIPASS` 下，`paths.resource_root()` 已兼容。
