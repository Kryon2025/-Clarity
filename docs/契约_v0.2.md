# 深清 v0.2 接口契约（QML ↔ Python）

> 本文件是界面层与逻辑层的唯一契约。QML 只读 `App.xxx` 属性、只调 `App.xxx(...)` 方法；
> Python 侧（bridge）负责实现并 emit 对应信号。改动任何名字都要同步改本文件。

## 1. 设计方向（本次改版）

- 从「导航 + 表单式页面」改为参考「禅定空间」的**空间卡片式首页**：大卡（超禅）+ 分组「轻禅」下的空间卡 + 「新增空间」。
- 视觉：**暗色优先 + 液态玻璃（Liquid Glass）**：大圆角、半透明玻璃层、1px 高光描边、柔和内阴影、背景光斑、噪点、弹性动画。
- 点空间卡 → 「空间设置」浮层（取消 / 标题 / 完成），可改：空间名称（≤20）、使用时长（15–240，步进 5）、氛围、允许使用的应用（白名单）。
- 「允许使用的应用」→ 全屏白名单页：搜索框 + 分类 chips（全部应用 / 工作学习 / 实用工具 / 其他）+ 应用列表（图标 + 名称 + 开关）。
- 锁机时：重度档全屏玻璃遮罩（剩余时间 + 空间名解释 + 进度）。
- 保留：数据页（统计）、设置页（主题 / 开机自启 / 插件）。

## 2. 数据模型（Space）

```json
{
  "id": "sp_1729...",
  "name": "睡眠",
  "minutes": 180,
  "atmosphere": "静谧",
  "allowed_apps": ["wechat.exe"],
  "super": false
}
```

- `super`：主卡「超禅」，只能有一个；新建时如无 super，可把第一张设为 super。
- `atmosphere`：氛围，取值来自 `App.atmospheres` 的 `value`。
- `allowed_apps`：白名单进程 exe 名；会话中命中白名单的进程**不结束**。

## 3. App 属性（QML 可见，只读）

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `spaces` | list<dict> | 全部空间，字段见 §2，并额外带 `allowedCount`（int）与 `atmosphereLabel`（str） |
| `superSpaceId` | str | 超禅空间 id（可能为空） |
| `spacesLight` | list<dict> | 非 super 的空间（「轻禅」分组） |
| `activeSpaceId` | str | 当前进行中的空间 id |
| `activeSpaceName` | str | 当前空间名（空闲时为空） |
| `atmospheres` | list<dict> | `[{value, label, color}]`，color 为 `#RRGGBB` |
| `appCatalog` | list<dict> | `[{exe, name, path, iconUrl, category}]` 允许使用的应用候选 |
| `state` / `busy` / `remainingText` / `remainingSeconds` / `totalSeconds` / `progress` | str/bool/int/float | 会话状态（同 v0.1） |
| `locked` | bool | 重度遮罩是否显示 |
| `canPause` / `pauseCount` / `pauseLimit` | bool/int/int | 暂停控制 |
| `todayMinutes` / `weekMinutes` / `streakDays` / `sessionCount` / `last7Days` | 数字/list | 统计（同 v0.1） |
| `theme` / `appName` / `appAlias` / `version` | str | 元信息 |
| `autostartEnabled` | bool | 开机自启 |
| `plugins` | list<dict> | `[{id,name,version,description,enabled,error}]` |
| `draftSpace` | dict | 供「空间设置」浮层读取的编辑副本 `{id,name,minutes,atmosphere,allowedCount}` |

## 4. App 方法（Slot）

**空间**
- `spacesNew()` → 新建空间并返回 id（同时 emit spacesChanged）
- `startSpace(id)` → 开始该空间会话（白名单生效、守护启动）
- `updateSpace(id, name, minutes, atmosphere)` → 保存名称/时长/氛围
- `deleteSpace(id)` → 删除
- `setSpaceAllowedApps(id, list)` → 设置白名单（exe 名列表）
- `toggleSpaceAllowedApp(id, exe, bool)` → 单个开关
- `beginEditSpace(id)` / `updateDraft(id, name, minutes, atmosphere)` / `commitEditSpace()` / `cancelEditSpace()` → 编辑草稿（浮层用；`updateDraft` 只改草稿不落盘）

**会话**
- `pauseSession()` / `resumeSession()` / `stopSession()`

**应用 / 统计 / 设置 / 插件**
- `refreshAppCatalog()` → 重新扫描本机可执行应用
- `refreshStats()` / `exportStats()` → str 导出路径
- `setTheme(name)` / `setAutostart(bool)` / `setDefaultMinutes(int)`
- `setPluginEnabled(id, bool)` → 启用/停用插件（emit pluginsChanged）
- `restartPlugins()` → 重新扫描插件目录

## 5. App 信号

`spacesChanged` `stateChanged` `tickChanged` `statsChanged` `catalogChanged` `pluginsChanged`
`lockedChanged` `settingsChanged` `themeChanged` `toast(str)` `guardEvent(str)`

## 6. 插件接口（Python，供插件作者使用）

```python
from shenqing.plugins.api import PluginBase, PluginAPI

class Plugin(PluginBase):
    def on_load(self, api: PluginAPI) -> None: ...
    def on_session_start(self, space: dict) -> None: ...
    def on_session_end(self, summary: dict) -> None: ...
    def on_process_blocked(self, exe: str) -> None: ...
    def on_tick(self, remaining_seconds: int) -> None: ...
```

- 目录：`%APPDATA%\\ShenQing\\plugins\\<id>\\`，含 `plugin.json`（id/name/version/api_version/author/description/entry）与入口 py。
- `api` 提供：`log(msg)`、`get_setting(key, default)`、`set_setting(key, value)`、`notify(title, body)`、`register_nav_page(title, qml_relative_path)`（可选）。
- 插件异常被 manager 捕获并写日志，不拖垮主程序。

## 7. 视觉规范（暗色）

| token | 值 | 用途 |
| --- | --- | --- |
| 背景 | `#05070A` → `#0B1220` 渐变 + 两团彩色光斑（蓝紫 #3B5BFF / 青 #22D3EE） | 页面底 |
| 玻璃层 | `rgba(255,255,255,0.06)` + 线性高光 `rgba(255,255,255,0.14)`→透明 | 卡片 |
| 描边 | `rgba(255,255,255,0.18)` 1px，顶部更亮 | 玻璃边缘 |
| 高光主色 | `#4F7CFF`（超禅卡用 `#1B4BFF` 渐变） | 强调 |
| 文本 | 主 `#F2F6FF`，次 `rgba(255,255,255,0.62)` | |
| 圆角 | 卡片 22px，按钮 999px（胶囊），面板 28px | |
| 动画 | 弹性 `Easing.OutBack` 220ms；卡片 hover 上浮 2px + 高光跟随 | |

> Qt 侧实现（v0.2 终版）：**优先用 `qml/glass/LiquidGlass.qml`** ——
> ShaderEffectSource 采样 Backdrop + GLSL 圆角透镜折射/色散/镜面高光，磨砂仅作可选低强度项。
> 阴影用 `MultiEffect`；纯色/噪点只做辅助。**不要再用大面积模糊 + 白雾堆磨砂感**（用户明确否掉）。
