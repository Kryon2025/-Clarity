# 国际化（i18n）

深清的多语言方案照着 **Class Widgets 2** 的做法：Qt 的 `.ts/.qm` + `pyside6-lupdate / pyside6-lrelease`，
再用 GitHub Actions 在源码变动时自动更新翻译源、编译产物并提交回仓库。

## 1. 三个角色

| 角色 | 位置 | 说明 |
| --- | --- | --- |
| 源文案 | `src/shenqing/**/*.py`、`**/*.qml` | QML 用 `qsTr("... ")`；Python 用 `QCoreApplication.translate("ShenQing", "...")` |
| 翻译源 | `src/shenqing/locales/<locale>.ts` | XML，`source` 是中文原文，`translation` 是译文 |
| 运行产物 | `src/shenqing/locales/<locale>.qm` | 二进制翻译，随包分发（`i18n.locales_dir()` 查找） |

支持的语言见 `src/shenqing/i18n.py` 的 `LOCALES`：`zh_CN`（源语言）、`en_US`（当前交付的英文版）。

## 2. 本地命令

```powershell
python scripts/i18n.py extract   # pyside6-lupdate：扫描 py+qml，更新所有 .ts
python scripts/i18n.py compile   # pyside6-lrelease：.ts -> .qm
python scripts/i18n.py check     # 统计未翻译条数（CI 里也跑这个）
```

## 3. 运行时加载

- 设置项 `language`：`auto`（跟随系统）/ `zh_CN` / `en_US`，默认 `auto`。
- 启动时 `app.py` 先创建 `Translator` 再加载 QML（QML 的 `qsTr` 在加载时求值，翻译器必须先装好）。
- `Translator` 会同时安装 RinUI 自带的 `RinUITranslator`（RinUI 控件的按钮/提示也会跟着换语言）。
- 设置页切换语言 → `App.setLanguage(code)` → 立即重装翻译器 + `engine.retranslate()`；托盘菜单在下次启动时生效。

## 4. GitHub 自动化（学 CW2 的 i18n-update.yml）

`.github/workflows/i18n-update.yml`：

1. **检测变更**：push 到 main 时看是否改了 `src/shenqing/**/*.py|qml` 或 `locales/*.ts`；
2. **更新翻译源**：装 PySide6 → `python scripts/i18n.py extract` → 自动 commit `.ts`；
3. **编译**：`python scripts/i18n.py compile` → 自动 commit `.qm`；
4. 手动触发（workflow_dispatch）可以只更新 `.ts` 或只编译 `.qm`。

与 CW2 的差异：CW2 的 `assets/locales` 换成 `src/shenqing/locales`，Python 版本换成 3.13，其余流程一致。

## 5. 加一门新语言

1. 新建 `src/shenqing/locales/<locale>.ts`（空骨架即可，`lupdate` 会填充）；
2. `python scripts/i18n.py extract` 抽取全部源文案；
3. 填 `<translation>`（可先留空，`check` 会标 TODO）；
4. `python scripts/i18n.py compile`；
5. 在 `src/shenqing/i18n.py` 的 `LOCALES` 里加一项，设置页会自动出现该语言按钮；
6. 提交 `.ts` 与 `.qm`。

## 6. 约定

- 品牌词（深清 / 身轻 / ShenQing）、路径、版本号、日志不翻译。
- 带变量一律用 Qt 占位符：`qsTr("已完成 %1% · 剩余 %2 分钟").arg(pct).arg(mins)`，不要字符串拼接。
- 中文原文即 key，所以**改文案等于改 key**：改完必须重新 `extract` + `compile`，旧译文会变成 "**obsolete**"（`check` 会提示）。
- 插件自己的 UI 文案同理走 Qt 翻译；插件可在自己的目录放 `.qm` 并在 `on_load` 里用 `QTranslator` 加载（API 0.1 暂未提供宿主注入，先自行管理）。

## 7. 当前状态

- 中文（源语言）：全部界面。
- 英文（en_US）：v0.4 起的首个外文版本，界面、设置、遮罩、灵动岛、速启面板、托盘/通知文案。
- 未覆盖：插件市场类文案（暂无）、错误堆栈（日志，不翻译）。
